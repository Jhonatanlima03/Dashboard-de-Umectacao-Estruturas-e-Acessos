# 💧 Dashboard de Umectação – Estruturas e Acessos

## 📌 Sobre o projeto

Este projeto consiste no desenvolvimento de um **dashboard operacional de umectação**, criado no **Microsoft PowerPoint**, com o objetivo de apresentar de forma visual e objetiva informações relacionadas à frota, volume de água utilizado, estruturas e acessos.

O dashboard foi desenvolvido para facilitar a visualização dos principais indicadores operacionais, permitindo identificar necessidades de atendimento, analisar rotas, dimensionar a frota e destacar possíveis riscos relacionados à operação.

## 🎯 Objetivo

O principal objetivo do dashboard é transformar informações operacionais em uma **visão gerencial clara e de fácil interpretação**, auxiliando no acompanhamento da operação de umectação.

Entre os principais objetivos estão:

- Acompanhar a frota atual;
- Identificar o volume de água utilizado;
- Comparar o volume atual com o volume necessário;
- Dimensionar a frota necessária para atendimento da operação;
- Analisar as principais rotas e acessos;
- Identificar regiões de maior necessidade operacional;
- Destacar riscos relacionados à operação;
- Apresentar um plano de ação para os principais pontos identificados.

## 📊 Principais indicadores

### 🚛 Frota

Apresentação da quantidade de caminhões disponíveis atualmente e da quantidade necessária para atender à demanda operacional.

### 💧 Volume de água

Comparação entre o volume atualmente utilizado e o volume necessário para atingir a demanda estimada.

- Volume atual: **330 mil L/dia**
- Volume necessário: **660 mil L/dia**

### 📍 Perímetro crítico

Identificação do perímetro considerado crítico para atendimento da operação:

- **Perímetro crítico: 30 km**

### 📈 Performance

Indicador destinado ao acompanhamento do desempenho da operação e da capacidade de atendimento das demandas identificadas.

## 🗺️ Análise de rotas

O dashboard apresenta as principais rotas e acessos considerados na operação:

- Dique de Segurança;
- Acesso Principal;
- DRM;
- Cimentação.

Para cada rota são apresentados dados como:

- Distância;
- Tempo estimado;
- Quantidade de caminhões;
- Capacidade dos caminhões;
- Necessidade de atendimento.

## ⚠️ Análise de riscos

O painel também apresenta riscos relacionados à operação, destacando pontos que podem impactar o funcionamento das atividades.

Entre os riscos apresentados estão:

### TAC

Possibilidade de ocorrência de multas e suspensão da operação.

### Comunidade e Saúde

Possibilidade de denúncias e exposição a particulados, reforçando a importância do controle adequado da umectação.

## 📋 Plano de ação

Com base nos indicadores apresentados, o dashboard propõe ações operacionais para melhorar o atendimento:

- Priorizar o atendimento do perímetro crítico de **30 km**;
- Direcionar caminhões para acessos com maior fluxo operacional;
- Reforçar a frota para atingir **660 mil L/dia**;
- Monitorar diariamente os indicadores de poeira e produtividade.

## 💡 Desenvolvimento

O dashboard foi desenvolvido utilizando o **Microsoft PowerPoint**, explorando recursos de criação e organização visual para transformar dados operacionais em uma apresentação gerencial.

Foram utilizados elementos gráficos, indicadores, formas, ícones, barras de progresso e estruturas visuais para criar uma interface semelhante a um dashboard tradicional.

O projeto teve como foco principal a **visualização de dados, organização das informações e comunicação de indicadores operacionais**.

## 🛠️ Tecnologia utilizada

- Microsoft PowerPoint

O dashboard proporciona uma visão consolidada da operação de umectação, permitindo identificar de forma rápida:
